# Realtek RTL8761BU Bluetooth firmware

`rtl8761bu_fw` and `rtl8761bu_config` are Realtek's firmware and config for the
RTL8761BU USB Bluetooth dongle. They correspond to `rtl_bt/rtl8761bu_fw.bin` and
`rtl_bt/rtl8761bu_config.bin` in
[linux-firmware](https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git).

They are **not** covered by carsh's GPL licence. Realtek allows redistribution
under [`LICENCE.rtlwifi_firmware.txt`](LICENCE.rtlwifi_firmware.txt) (copied from
linux-firmware), which must accompany these files. It also forbids reverse
engineering them.
